# Private evidence-coverage presentation

`../coverage.tsx` seals this library behind CoverageSection and supportsRecordedRoot. The caller supplies one already admitted context at a time: attention, aggregate overall, backward or impact. This library does not parse raw input, combine directions, infer provenance, alter checks/limits/usage, query a graph or change public types.

Groups follow each code's first occurrence and retain every supplied entry and every evidence reference, including duplicates, in original within-code order. Counts say supplied entries, not failures or events. Node IDs/references are plain escaped disclosure text, never URLs/actions. No gap is hidden by a source-reported complete flag. An empty list does not verify completeness, and absent backward evidence stays explicitly unknown.

Root support here is presentation over an explicit admitted root and supplied complete, gap-free backward coverage. Aggregate or impact incompleteness does not remove that support. Missing backward evidence cannot create it; the caller retains the actual reported root/path/selection and chooses reported wording. Existing relationships admission remains responsible for rejecting inconsistent evidence before this library runs.
