Add cumulative same-run live recording updates and opt-in lazy recorded subflows through a shared recording source, task/idle preparation, frame-batched ready publication and an optional host-owned worker bridge. ExplainableShell and TraceViewer expose themed loading/error/retry states through props and JSON layout options while preserving exact invocation identity and Backtrack evidence handling. Live updates retain the selected runtime stage when parallel branches grow, publish complete cohorts without dropping recorded events and refuse rewritten history.

Built-in state, diff, result and debug views display accepted BigInt, Date, Map and Set values through a shared bounded formatter. Unsafe or truncated values have explicit markers; recorded getters and serialization methods are not invoked.
